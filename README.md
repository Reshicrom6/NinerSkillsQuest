# Niner Skills Quest

A local demo for exploring how coursework can suggest skills for a student profile.
Coursework suggestions represent possible exposure, not verified skill mastery.

## Setup

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Vite prints a local URL after the development server starts.

## Commands

```sh
npm run build
npm test
```

## Demo and limitations

The current demo displays a small illustrative course catalog and its suggested
skills. The course mappings are not official catalog data. Authentication,
transcript upload, and backend services are not included.

## AI-use disclosure

AI assistance was used to scaffold and implement this project. The demo catalog
and course-to-skill mappings are illustrative and should be reviewed against
official course information before being treated as authoritative.
